# 可忽略报表清单
# 这些报表因以下原因不计入质量检查：
#   still_zero   - 设置默认日期参数后数据仍为零（需额外勾选航司/航线等下拉参数）
#   export_fail  - FineReport 导出 API 不兼容此报表格式
#   timeout      - 报表过大导致导出超时

## 仍全零 — 需特定参数（航司/航线下拉等）才能出数据
still_zero | 后台管理目录/填报报表/大客户团队人员信息填报.xlsx
still_zero | 后台管理目录/日成本准确性提升/日成本自动计算科目数和金额占比统计报表.xlsx
still_zero | 市场经营指标/主要经营指标/飞行小时班次表.xlsx

## 导出失败
export_fail | 市场经营指标/价格管控/短期开关舱明细.xlsx

## 超时
timeout | 市场经营指标/商委激励考核/独飞航线市场对标数据.xlsx
