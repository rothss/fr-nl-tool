OPM NL Report Query

用自然语言查询 OPM 报表数据的智能技能

项目简介

OPM NL Report Query 是一个智能技能，用于桥接业务语言问题与 OPM 报表数据检索。它通过解析自然语言意图、 排序匹配的报表、从本地 OPM 镜像 Excel 文件中提取结构化数据行，并可选地回退到实时导出，来回答关于 OPM KPI 的自然语言问题。

当用户提出如"我的包干航线的客座率是多少"、"HU7778 明天的余票"或"未来航班竞航价格差"等问题时， 此技能能够理解问题意图并返回结构化的答案。

核心功能

  • 自然语言意图解析，支持规则解析和 LLM 辅助
  • 智能报表路由和数据源选择
  • 本地 Excel 文件与实时导出的混合策略
  • 结构化的中间输出和最终答案
  • 多指标提取（如同时查询客座率和票价）
  • 时间语义解析（支持"未来两天"、"近三天"等表达）
  • 航线/机场别名规范化
  • 竞争对手分析诊断

技术栈

Python PowerShell Node.js YAML 配置 JSON Schema OpenAI SDK Excel 处理

工作流程

1输入规范化
2意图解析
3查询规划
4数据获取
5结构化提取
6分析引擎
7答案渲染

快速开始

构建报表目录

python scripts/build_report_catalog.py

自然语言查询

python scripts/runner.py "我的包干航线的客座率是多少" --user zhuanz --output-format json

OpenClaw 集成

重要：OpenClaw 应通过 scripts/runner.py 调用此技能，而不是直接使用 query_opm_nl.py。 runner.py 是稳定的技能接口，返回 OpenClaw 应消费的结构化信封。

OpenClaw 集成规则：

  • 将此技能作为单一工具调用 scripts/runner.py
  • 消费返回的 JSON 信封，而不是直接检查 Excel 文件
  • 如果技能返回结构化失败，不应运行临时命令
  • 本地意图 LLM 仅可用于填充缺失的槽位

高级功能

本地意图 LLM

如果需要使用本地小模型辅助槽位填充，设置环境变量：

$env:OPM_NL_INTENT_LLM_COMMAND = "your-local-intent-parser-command"

实时导出回退

如果本地文件缺失、过时或包含仅标题的导出，可以触发实时导出：

pwsh -NoProfile -File scripts/export_report_live.ps1 -ReportName "未来航班客座率票价分析"
